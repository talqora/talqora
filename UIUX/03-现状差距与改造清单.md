## 2. 不照搬项(刻意保留差异)

| 微信做法 | 是否照搬 | 理由 |
|---|---|---|
| 竖栏头像距顶 52(给 macOS 红绿灯让位) | **否**,取 24 | Web 没有原生窗口控件,52 会变成一块莫名其妙的白 |
| 竖栏毛玻璃 / vibrancy 半透明 | **否**,固定色值 | Web 没有系统级 vibrancy,`backdrop-filter` 在长列表上掉帧且跨浏览器不一致 |
| 消息列表隐藏滚动条 | 是 | 微信不显示滚动条,保持 |
| 语音「按住说话」、截图、红包/转账 | **否**,保留图标占位 no-op | 缺音频采集/截图/支付链路;只保证视觉位置一致 |
| 列表左滑操作、未读红点、置顶分组 | **否** | 属产品功能,不在「还原视觉」范围 |

## 4. 验收标准

1. **结构**:1000px 宽窗口下,竖栏 60 / 列表 240 / 聊天区 400;聊天头部 52;输入框四周内缩 8(底部 12)。
2. **配色**:深浅两套下,列表与聊天区的明度关系与 [02 §7.3](./02-实测设计规范.md#73-关键规律深色模式不是浅色取反) 一致——浅色列表暗于聊天区,深色列表亮于聊天区。
3. **列表行**:36 头像 + 14 标题 + 12 预览 + 11 时间 + 左缩进 58 的分隔线,单行 64。
4. **输入区**:盒子有 1px 描边与 6px 圆角,工具栏在**盒子内部底部**,发送按钮在**右下**,空内容时为灰态、有字转绿。
5. **门禁**:`pnpm lint && pnpm test` 通过;`agentView` 的既有测试不因输入框重构而失败。
